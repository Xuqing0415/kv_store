# 架构设计文档

## 系统概览

KV Store 是一个基于 LSM-Tree 架构的嵌入式键值存储引擎，集成 Raft 共识协议实现强一致集群复制。系统分为四层：客户端层、Raft 共识层、LSM 存储引擎层、可观测性层。

## 核心组件

### 1. MemTable（内存表）

- **数据结构**：跳表（SkipList），O(log n) 插入/查找
- **写入流程**：所有写入先进入 MemTable，同时写 WAL 保证持久性
- **切换机制**：达到 `MEMTABLE_SIZE_LIMIT`（默认 256KB）后切换为 Immutable MemTable，后台刷入 SSTable

### 2. WAL（Write-Ahead Log）

- **格式**：CRC32 + Type + KeyLen + ValLen + Key/Val
- **滚动**：超过 100MB 自动滚动到新文件
- **归档**：MemTable 成功刷盘后，旧 WAL 自动归档
- **崩溃恢复**：启动时按序重放 WAL，将未刷盘数据恢复到 MemTable
- **Raft 模式**：WAL 被禁用，由 Raft 日志统一持久化

### 3. SSTable（Sorted String Table）

- **文件格式**：Data Blocks → Filter Block → Index Block → Footer
- **数据块**：前缀压缩 + 重启点（每 16 条记录一个重启点）
- **压缩**：支持 Zstd / LZ4 / 无压缩，块级压缩
- **索引**：每个数据块的 last_key → offset 映射
- **Bloom Filter**：SSTable 级布隆过滤器，加速不存在键的查找

### 4. Compaction（合并压缩）

- **分层策略**：Level 0 文件数阈值触发，Level 1+ 按大小阈值触发
- **合并流程**：读取源层和目标层文件 → 归并排序 → 写入新 SSTable → 删除旧文件
- **Tombstone GC**：合并过程中丢弃已标记删除的键
- **后台线程**：独立 worker 线程，每秒检查一次触发条件

### 5. Raft 共识

详见 [Raft 实现文档](RAFT_IMPLEMENTATION.md)。

### 6. 网络层

- **RESP 服务器**：Redis 序列化协议兼容，支持 SET/GET/DEL/KEYS/SCAN 等命令
- **Raft RPC**：二进制协议，支持 VoteRequest/AppendEntries/Propose/InstallSnapshot
- **Metrics 端点**：HTTP `/metrics` 端点，Prometheus 文本格式

## 并发模型

- **读写锁（RWLock）**：MemTable 操作使用读写锁，读多写少场景友好
- **Manifest 锁**：独立的互斥锁保护 SSTable 文件清单
- **原子计数器**：指标统计使用原子操作，无锁读取
- **后台线程**：
  - MemTable 刷盘：同步，在写入线程中触发
  - Compaction：独立 worker 线程
  - 维护线程：定期内存回收（malloc_trim + posix_fadvise）

## 持久化保证

| 场景 | 保证 |
|------|------|
| 正常关闭 | 所有数据刷入 SSTable |
| 进程崩溃 | WAL 重放恢复未刷盘的 MemTable 数据 |
| 磁盘故障 | 依赖操作系统/文件系统级保护 |
| Raft 集群 | 多数派确认后提交，日志持久化到磁盘 |

## 内存管理

- **自定义分配器**：`kv_malloc`/`kv_free`/`kv_realloc` 封装，便于追踪
- **LRU 缓存**：SSTable 数据块缓存，默认 1024 个条目
- **维护线程**：每 30 秒执行 `malloc_trim(0)` 释放堆碎片
- **页缓存控制**：`posix_fadvise(POSIX_FADV_DONTNEED)` 释放已刷盘文件的页缓存

## 关键设计决策

| 决策 | 原因 |
|------|------|
| 跳表而非 B+ 树 | 实现简单，无锁并发友好，内存写入性能优异 |
| 前缀压缩而非字典压缩 | 块内相邻 key 共享前缀，压缩率高且解码简单 |
| 二进制 Raft RPC 而非 gRPC | 无外部依赖，跨平台兼容，协议简单 |
| 内置 Zstd 而非系统库 | 避免版本依赖，确保跨平台一致性 |
| WAL 滚动归档而非循环 | 崩溃恢复时可快速定位未刷盘数据 |
